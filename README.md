 # hospital-management-system
DBMS Capstone Project - Hospital Management System
### Project Description

The Hospital Management System is a relational database designed to manage
patients, doctors, departments, wards, appointments, treatments,
prescriptions and billing information.

## Technologies Used

- MySQL
- SQL
- MySQL Workbench
- GitHub

## Main Modules

- Patient Management
- Doctor Management
- Department Management
- Ward Management
- Appointment Management
- Treatment Management
- Prescription Management
- Billing Management
